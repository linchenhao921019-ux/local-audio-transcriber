# 本地音频转录

一款面向 Apple Silicon Mac 的本地音视频转文字工具，可将录音或视频快速整理成带时间戳的转录文本和文档。

## 功能

- 支持 `wav`、`mp3`、`mp4`、`mov`、`m4a`，可选择文件或直接拖入窗口。
- 生成带时间戳的转录文本、Markdown 和 Word 文档。
- 自动恢复中文标点，并在软件内预览转录结果。
- 可连接本机 Ollama，生成重点大纲和会议纪要。
- 支持自定义输出目录，并会记住用户选择。

## 特点

- 全程本地离线转录，录音无需上传云端。
- 已内置语音识别模型和离线运行环境，安装后即可使用。
- 原生 macOS 界面，支持任务取消和自动分段。
- 仅支持 Apple M 系列芯片，不支持 Intel Mac。
